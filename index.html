DormSync

Digital Shared Accommodation Management System

Java Swing • MySQL • JDBC

About the Project

DormSync is a desktop-based management system for hostels and shared accommodation facilities. It provides a complete solution for managing rooms, tenants, payments, chores, and visitors — with separate experiences for Admins (who manage everything) and Users (who view their own data and update their profile).

Built using Core Java with a clean MVC + DAO architecture, the application connects to a MySQL database and offers a modern, custom-styled GUI.

Technology Stack

Java (Core) Java Swing JDBC MySQL 8.0 Apache NetBeans OpenPDF Apache POI

Key Features

🛡️ Role-Based Access

Admin and User roles with distinct dashboards and permissions.

🏠 Room Management

Airbnb-style card grid showing all rooms with type, capacity, and availability.

👥 User Management

Admins can promote, demote, delete, or reset passwords for any user.

💰 Payment Tracking

Record payments with method, date, and status. Auto-generate monthly rent.

🧹 Kanban Chore Board

Visual 3-column board (Pending / In Progress / Completed).

🔍 Search & Sort

Live search on every table, plus column sorting.

📄 PDF Export

Export payment reports to professional PDF files.

👤 Profile Management

Users edit their own name, phone, and password.

Architecture

DormSync follows the MVC-inspired DAO pattern:

  • gui — All Swing frames and UI components
  • dao — Database operations (SQL queries)
  • model — Plain Java classes (User, Room, Payment, etc.)
  • util — Shared helpers (DBConnection)

This clean separation makes the code maintainable, testable, and scalable.

Roles

Admin can: Manage rooms, allocations, payments, chores, visitors, users, and generate PDF reports.

User can: View own payments, visitors, chores, and edit their own profile.
